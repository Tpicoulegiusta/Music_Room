# Music Room

**Music, collaboration and mobility.** A real-time collaborative music app, built as a 42 project.

> [!NOTE]
> 🚧 **Work in progress.** The code will land in this repository as the project moves forward.

## The idea

Music Room lets several people listen to music and shape it together, live, from their phones: suggest the next track and vote for it, edit a shared playlist in real time, and hand over control of the player to friends.

## Planned features

- [ ] **Track vote**: people in a room suggest tracks and vote, and the most popular one plays next
- [ ] **Collaborative playlist**: several users edit the same playlist at the same time
- [ ] **Control delegation**: give a friend control of the player
- [ ] Public and private rooms, with invited users and permissions
- [ ] Real-time sync between every connected device
